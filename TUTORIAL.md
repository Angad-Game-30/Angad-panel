# Angad-Panel Installation Tutorial

This repository contains:
* **TUTORIAL.md** – Step-by-step installation instructions
* **LICENSE** – GNU General Public License v3.0
* **Extension** – The adaptive window-aware Cinnamon panel extension
* **Panel Theme** – The custom Cinnamon theme built to work with the extension

**Step 1:** Install the **Angad-Panel** by clicking on the green button saying **<>code** and then **Download ZIP**, after that unzip it.

**Step 2:** go inside the folder and find the **Angad-Panel** file, it contains the Panel itself, after you find it, put it into the **.themes** folder.
If you can't find **.themes**, if you are at the home page, you can try to hit **ctrl+H** to show hidden files or you can find it in **/home/(your username)/.themes** if you don't have a **.themes** folder, then create one yourself like the **/home/(your username)/.themes**

**Step 3:** Ok, now open **Themes** and on panel, use **Angad-Panel**

**Step 4:** Now you have to find the extension that is inside the unziped file named: **rounding-toggle@Angad-Game-30**, put it into **/home/(your username)/.local/share/cinnamon/extensions**

**Step 5:** Open Extensions and go to manage, click on **Rounding/floating Toggle** and hit the **+** Icon to apply

**Step 6:** Now hit **alt+F2** and then **r** hit **enter** to restart cinnamon and now you have the **Angad-Panel**

**CONGRATS!!!**
